# Strategic analysis playbook

Use this modifier only when the user explicitly asks for a strategic, national,
or WK-level analysis. It adds interpretation to the selected route; it does
not authorize extra tools or replace authoritative retrieval.

## Sequence

1. State the scope, report year, uncertainty level, unit, and comparison
   period before interpreting results.
2. Use the route's bound SQL or semantic capability to obtain the evidence.
3. Separate measured values, derived calculations, and recommendations.
4. Rank contributors with an explicit denominator and explain material
   concentration. Include project remarks or GROOVY report content only when
   it was returned by retrieval.
5. Call out missing values, duplicate grain, filters, and unresolved entities.

## Evidence boundary

Do not infer project priority, maturity, forecast success, or national impact
from names or ranked search hits. Use the schema and knowledge tools for
definitions and the database/search results for current facts. Keep GROOVY
report content distinct from the GROOVY active/status flag.

## Forbidden shortcuts

- Do not invent values, units, thresholds, or maturity transitions.
- Do not silently mix report years, uncertainty levels, or project grains.
- Do not present a semantic candidate list as an exhaustive count.
- Do not broaden a WK request to national scope without saying so.
